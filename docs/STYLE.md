# Crossover Design System

The site should use a small number of shared typography, color, icon, and component roles.

---

## Typography

Typography role	CSS selector
Page title	h1
Section heading	h2
Subheading	h3
Body text	body / p
Navigation	.app-nav
Metric number	.metric-value
Secondary text	Not yet defined
Metadata	Not yet defined


.text-page-title    { font-size: 24px; font-weight: 700; }
.text-section       { font-size: 20px; font-weight: 700; }
.text-subheading    { font-size: 16px; font-weight: 700; }
.text-body          { font-size: 16px; font-weight: 400; }
.text-secondary     { font-size: 14px; font-weight: 400; }
.text-meta          { font-size: 12px; font-weight: 400; }
.text-metric        { font-size: 24px; font-weight: 700; }
