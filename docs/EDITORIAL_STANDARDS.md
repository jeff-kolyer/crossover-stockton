# Living investigations: editorial updates

An article's main text states our best current understanding. When new evidence changes that understanding, revise the present-tense narrative. Preserve consequential developments in a dated editor's update near the start of the article. Do not leave an obsolete statement in the main text merely to preserve history.

- **Update:** New event, evidence, or finding. Give the event date, describe what changed, and link to supporting public records when available.
- **Correction:** A substantive error in our reporting. Label it clearly and state what was wrong and what was fixed. New evidence is not itself a correction.
- **Revision:** Changes to wording, structure, or clarity that do not change substance. No public log entry is needed.

Keep the original publication date and last-updated date separate. An update's event date can differ from the date we edited the article. Preserve source dates, attribution, and uncertainty; do not infer an animal outcome from a case disposition. Thank organizations for documented cooperation without implying partnership or endorsement. The public update history records meaningful editorial developments, while Git retains technical revisions.

Before linking or publishing a received file, review it for sensitive content and decide whether a public copy is suitable. A link to an activity record can document receipt without exposing the raw file.
