# Site design rules

## Link arrows

Use the inline SVG `right-arrow` for internal navigation, with path `M13.5 4.5 21 12m0 0-7.5 7.5M21 12H3`. Use the inline SVG `external-arrow` for diagonal links, with path `m4.5 19.5 15-15m0 0H8.25m11.25 0v11.25`. Display both at 1.05em with a 1.75 stroke. Do not put arrows on status labels. Apply these shapes to regenerated pages.

## Civic heart

Render the heart in article copy with the inline `civic-heart` SVG using path `M21 8.25c0-2.485-2.099-4.5-4.688-4.5-1.935 0-3.597 1.126-4.312 2.733-.715-1.607-2.377-2.733-4.313-2.733C5.1 3.75 3 5.765 3 8.25c0 7.22 9 12 9 12s9-4.78 9-12Z`, displayed at 1.05em with a 1.75 stroke and the site's accent color.
