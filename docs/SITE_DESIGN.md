# Site design rules

The public site is a rendering of `src/feed.json` and the canonical records in `src/data/`. The active visual layer is `public/preview/site-md.css` and `public/preview/site-md.js`. `SITE.md` defines page and navigation behavior.

Keep one civic type and icon system across Home, About, gap sections, and record pages. Use restrained navy, teal, white, documentary imagery, clear links, and readable source context. A layout change must not change the meaning or provenance of a record.

The Crossover homepage introduces the decision to engage with real needs and provides one obvious route into the first gap. The gap Overview documents the investigation, including the last substantive update, current work, figures, uncertainties, and links to supporting records. About carries the wider technological and vocational context.

Images used for atmosphere are not evidence. Any documentary photograph used as evidence needs a source and context. Reported conditions, plans, firsthand observations, and measured outcomes must remain distinguishable in text and links.

The daily reading is prose drawn from the same feed. It should not recite interface labels or include deployment dates as investigation updates.
