# Site Design Specs


## Menu Items

Overview is the entry page. There is no separate Index page. The logo returns to Overview.
Pages use ordinary URLs without hash fragments.

Section tiles show more detail in full mode than on mobile.


## Contextual Breadcrumbs

Overview is the root of section breadcrumbs. Record breadcrumbs include the section the reader came from.


## Menu

In full-screen, there is a LEFT full height menu. On mobile, the menu is in the TOP RIGHT corner.

## Top Header

There is a top header with "About" link to the right.

The menu is sticky. The LOGO is part of the LEFT menu in full-screen mode.
